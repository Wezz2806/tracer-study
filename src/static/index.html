Arsitektur Dual-Model Transformer IndoBERT
110 Juta Parameter

Spesifikasi Arsitektur

  • Model Dasar: indobenchmark/indobert-base-p1
  • Lapisan Transformer: 12 Lapisan Encoder Tersembunyi
  • Hidden Dimension ($d_{\text{model}}$): 768 Dimensi
  • Multi-Head Attention: 12 Kepala Atensi
  • Total Parameter: ~110.000.000 Parameter
  • Subword Tokenizer: WordPiece Tokenizer (~30.000 Vocab)

Alur Pemrosesan Dual-Model

  • Model 1 (Topik Kritik/Saran): 5 Kelas Linear Classification Head $(768 \rightarrow 5) + \text{Dropout}(0.2)$
  • Model 2 (Sentimen Testimoni): 2 Kelas Linear Classification Head $(768 \rightarrow 2) + \text{Dropout}(0.2)$
  • Fungsi Loss: Categorical Cross Entropy Loss
  • Optimizer: AdamW ($\text{LR}=2\times 10^{-5}, \text{Weight Decay}=0.01$)

Metode Endpoint Fungsi
